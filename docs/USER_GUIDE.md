# ChainBox 使用说明

## 安装

1. 从 [Releases](https://github.com/dukangalex/ChainBox/releases) 下载 **ChainBox-android.apk**。
2. 允许安装未知来源应用后安装。
3. 同一签名且 versionCode 更大的新版可直接覆盖。

设置 → 应用版本 应与 Release tag 一致（如 1.0.5）。

## 导入配置

1. 仪表 → 添加配置。
2. 先导入**前置机场**订阅，设为当前配置。
3. 再导入**落地**配置（VPS 或另一份订阅）。落地不必设为当前配置。

## 链式代理

目标：网站看到的是落地 VPS IP。

1. 当前配置 = 前置机场。
2. 打开 **工具 → 链式代理生成器**。
3. 选择落地分组或节点。
4. 点 **保存并固定为链式出口**。
5. 重载服务，用浏览器查 IP。

正确结果：公网 IP = VPS。  
若仍是机场 IP：取消链式 → 更新订阅 → 再保存一次落地 → 重载。

订阅更新后不必重新点选落地，只要曾经「保存并固定」。

**取消链式**：同一页点「取消链式」，出口回到当前机场。

## 配置覆盖

路径：**设置 → 配置覆盖**。开关只改运行时，不改订阅文件。

| 开关 | 作用 |
|------|------|
| 配置规范化 | 清理不兼容字段，补齐 direct/block，注入常见 STUN 端口拦截 |
| 严格路由 | TUN `strict_route` |
| DNS 防泄漏倾向 | DNS 独立缓存、自动探测网卡 |
| 禁用 IPv6 | DNS `ipv4_only`，拦截 IPv6 |
| 禁用 QUIC | 拦截 UDP 443 |
| 排除国内 QUIC | 国内 UDP 443 走 direct，其余仍拦 |

建议先开「配置规范化」。

## 备份

**设置 → 备份与恢复**。

## 调试

**工具**页：网络质量 / STUN / 崩溃报告。「出站 = 默认」走当前链式或当前配置出口。

## 常见问题

**必须卸载才能装新版**  
debug 与正式签名混过。卸载后装正式 `ChainBox-android.apk`，以后同一 keystore 可覆盖。

**点更新闪退**  
versionCode 没变大或签名不同。换正式版并且版本号递增的包。

**检测 IP 是机场不是 VPS**  
链式未生效。取消 → 更新 → 再保存 → 重载。
